# Logic Tensor Networks — Research Reproduction

## Overview

This repository contains a research reproduction and study implementation of Logic Tensor Networks (LTNs) based on published neuro-symbolic AI research papers.

The main objective of this project was to:

* Understand the fundamentals of neuro-symbolic AI
* Study how logic and neural networks can be integrated
* Reproduce important LTN experiments from research papers
* Analyze model behavior and results
* Compare Logic Tensor Networks (LTNs) with Markov Logic Networks (MLNs)

This work was completed as part of an academic research and learning project.

---

# Topics Covered

## 1. Friends & Smokers Problem

Implemented the classic statistical relational learning problem using Logic Tensor Networks.

Key concepts explored:

* Logical predicates
* Relational reasoning
* Soft constraints
* Knowledge base satisfiability
* Inference using learned logical relationships

---

## 2. Semantic Image Interpretation (Pascal-Part Dataset)

Studied the use of LTNs for semantic image interpretation using the Pascal-Part dataset.

Key concepts explored:

* Object classification
* Part-whole relationships
* Logical consistency in predictions
* Semantic reasoning in images
* Integration of logical constraints with neural models

---

## 3. Unified LTN Framework for Multiple ML Tasks

Studied how LTNs can handle different machine learning tasks under a single framework.

Tasks explored include:

* Binary Classification
* Clustering
* MNIST Arithmetic Learning
* Multiclass Classification
* Parent-Ancestor Reasoning
* Propositional Logic
* Regression
